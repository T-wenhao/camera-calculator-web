# 光学方案计算器 · 单文件离线版

主文件：`index.html`

## 使用方法

1. 双击 `index.html`，或在 Windows 浏览器中打开。
2. 选择内置相机或自定义相机，并填写近远工作面、视场、分辨率、最大允许 F 值和可选运动采样条件；对焦距离留空时自动计算。
3. 点击“计算并推荐焦距”。
4. 查看推荐焦距、景深所需最低 F 值、建议工作光圈、理论景深、视场锥、全部标准焦距及淘汰原因。
5. 可复制或下载白底 PNG；“打印 / PDF”使用浏览器打印功能。

输入被修改后，页面会保留并标记上一次有效结果，同时暂停导出；重新计算成功后恢复。

本文件使用与正式网页相同的有限共轭二维光学求解模块。结果均为理论选型值，实际镜头仍需复核主平面、畸变、MTF 与装调误差。3D 三角测量将在后续阶段独立实现。
