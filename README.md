# 光学方案计算器

面向光学方案与现场调试工程师的二维线扫相机光学选型工具。指定相机后，根据近端和远端工作面、可选对焦位置、视场需求、分辨率要求、最大允许 F 值及可选的运动采样要求，输出焦距可行区间、推荐标准焦距、景深所需最低 F 值、建议工作光圈、理论景深、三个工作面的视场与像素当量，以及光学方案参数表。

## 数值边界

- 使用有限共轭理想薄透镜和几何离焦关系，不使用远距离视场速算式。
- 工作距离以物方主平面为基准。
- 对焦距离可留空；自动值采用近端、远端弥散圆要求相等的精确解，不使用工作区间中点近似。
- 最大允许 F 值默认 F/11，并作为硬约束参与焦距筛选；若景深必须收得更小，会显示真实所需 F 值和冲突，不会截断为 F/11。
- 设计弥散圆为 `2 × 像元尺寸`；`3 × 像元尺寸`仅展示参考景深。
- 550 nm 可见光参考波长仅产生衍射复核提示，不单独否决方案。
- 输出均标记为“理论选型值”；具体镜头确定后仍需用厂商数据或实物标定修正。

## 本地运行

需要 Node.js `>= 22.13.0`。

```powershell
npm install
npm run dev:local
```

然后打开 <http://localhost:3000/>。

## 验证

```powershell
npm test
```

该命令依次验证权威光学求解模块、完成站点构建，并检查服务端输出是否包含正式工程表。

## 页面

- `/`：正式二维光学方案工程表；保留 3D 后续阶段入口。
- `/prototype`：可抛弃的 A / B / C 界面对比原型，仅用于追溯界面决策。

## 离线交付

应用运行时不使用登录、后端、上传或外部网络请求。执行以下命令可从同一个权威求解模块重新生成单文件版本：

```powershell
npm run build:standalone
```

生成结果位于 `outputs/optical-calculator/index.html`，可直接双击打开，不需要 Node.js 或服务器。
